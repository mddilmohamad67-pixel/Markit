# Markit

Starter monorepo scaffold for the Markit Online Grocery + Marketing platform.

Contents:
- apps/web: Next.js frontend (PWA-ready, i18n stub)
- apps/api: Express API with Mongoose models and Firebase token verification middleware
- docker-compose.yml + Dockerfiles for local development
- openapi.yaml starter
- seed/seed.js sample seeding script

See README for quick start.
